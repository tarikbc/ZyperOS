# Wi-Fi File Transfer and USB File Transfer's page (res/web, DESIGN.md
# 11.15): what a phone or a computer shows, in the handheld's language.
# tools/i18n.py writes these into res/web/i18n/<code>.js, the page's t() and
# tn() read them by the name after "web." (app.js says how). The page's own
# style: buttons and headings in sentence case in English too, messages end
# with a full stop, status values lowercase. "the handheld" is the console
# the page talks to.
