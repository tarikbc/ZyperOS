# The play page (res/web/play, served by p2d): what a friend's phone or
# laptop shows while it is a player of the game on the handheld (player 2 on
# the NES; up to player 4 where a system has more), in the handheld's
# language. tools/i18n.py writes these into res/web/i18n/<code>.js
# beside the File Transfer page's, by their whole ID; play.js's t() reads
# them. The page's style is the File Transfer page's (web.txt): sentence
# case, messages end with a full stop. The pad's buttons keep the names
# printed on the handheld (A, B, SELECT, START), never translated.
