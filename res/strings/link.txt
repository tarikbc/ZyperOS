# The Game Boy's Link Cable (src/link.c, src/link_screen.c, src/linkpanel.c): the in-game
# menu's row on a Game Boy or Game Boy Color game on Gambatte, the page it opens over the
# paused game (Host and Join, waiting for the other handheld, the hosts found, linked), and the
# notices over the game as the link is made, lost or left; the code the host shows and the
# joiner types. Pixel 2 is the handheld's name and
# is never translated, and never broken: a no-break space between its two words. Its keys are keyhint.txt's, its Needs Wi-Fi menu.txt's.
