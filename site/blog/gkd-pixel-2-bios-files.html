Most retro systems run on the GKD Pixel 2 with nothing but the game. A few, mostly the CD consoles, also need the console's own startup code, its BIOS, as a file on the card. With ZyperOS the BIOS files go loose in one folder, Bios/, under the exact names below. This guide lists every system that needs one, and the ones where it is optional.

Where BIOS files go

Put them loose in Bios/ at the top of the card, not in a folder per system. ZyperOS hands that folder to each emulator, and the emulator asks for a file name inside it. Three exceptions use a folder of their own: the Neo Geo CD, the Dreamcast family and MSX2, as the table says.

The names must match exactly, capitals included. A file you dumped yourself may carry another name: rename it to the one here.

ZyperOS does not come with BIOS files: they are the console makers' code. Dump them from consoles you own.

Optional: they run without one

  • Game Boy Advance runs on the emulator's built-in BIOS. Add gba_bios.bin for the original boot animation.
  • Atari 7800 runs without one. Add 7800 BIOS (U).rom for the Atari logo at the start.
  • Atari 5200 and Pokémon Mini run without theirs, 5200.rom and bios.min.
  • 32X needs none.

Systems that need nothing

The NES, SNES, Game Boy, Game Boy Color, Genesis, Master System, Game Gear, TurboGrafx-16 HuCards, Nintendo 64, Virtual Boy, WonderSwan, Neo Geo Pocket, Atari 2600, Vectrex, Game & Watch, PICO-8, ScummVM and OpenBOR need no BIOS file.

J2ME is a special case: its emulator, FreeJ2ME-Plus, brings its own Java. The first J2ME game you start unpacks it into Bios/, about 60 MB, which takes a little while once.

Getting them onto the card

Copy them with the card in a computer, or open the BIOS folder on ZyperOS's File Transfer page in a browser and drop them there. The adding games guide shows both ways.
