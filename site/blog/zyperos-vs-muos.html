muOS, by MustardOS, runs on many handhelds, and its October 2026 release, 2606.0 "Andromeda", has an image for the GKD Pixel 2. It has a guided tour, a web dashboard for files, and video previews. This is muOS beside ZyperOS, from each project's own code, docs and releases as of 7 November 2026, with a dash wherever no source says either way.

The short answer

  • Pick muOS if you want a large catalogue of systems, DraStic and PortMaster included, a web dashboard to manage files over Wi-Fi, a guided tour of each screen, and a media player with live TV and radio.
  • Pick ZyperOS if you want box art fetched on the handheld, games sent over the USB cable as well as Wi-Fi, a charging screen while off, and a charge limit. ZyperOS 1.0.1 is out, with a card image and ZyperOS Installer.

Installing

muOS's Pixel 2 device page links the 2606.0 image from file hosts and a torrent, with a SHA-256 hash; it is not on GitHub. Its install page asks for a quality card of 16 GB or more, recommends Raspberry Pi Imager, and says balenaEtcher is not recommended. ZyperOS's release has a card image you write with any image writer, and ZyperOS Installer, which downloads and writes it for you. The install guide covers the steps.

Wi-Fi and adding games

muOS's device notes say the Pixel 2 has no Wi-Fi and gets online only with a supported USB Wi-Fi dongle, with network support off until you turn it on. Its Pixel 2 network config loads the RTL8188EU driver, and its docs name no adapter models. With Wi-Fi, muOS 2606.0 adds a Web Dashboard with file management, uploads and downloads included, plus SFTP and Syncthing.

ZyperOS is tested with the TP-Link TL-WN725N, an RTL8188EUS adapter. Over Wi-Fi, over its own network, or over the USB cable with no Wi-Fi, it opens one web page in any browser. See the Wi-Fi guide and adding games.

Box art, previews and the first start

On muOS, box art, previews and descriptions come from catalogue folders on the card, which its Web Dashboard can edit; we found no scraper on the handheld in its sources. Since 2606.0 its catalogue plays video previews. ZyperOS fetches covers on the handheld from libretro, ScreenScraper and SteamGridDB, and turns a cover into its video snap.

Both help on the first start: muOS with a setup screen and a guided tour that explains each screen the first time you open it, ZyperOS with a tutorial that teaches each button and asks for the theme, the home screen, the sounds and the music.

DS, PortMaster and media

muOS runs the DS on standalone DraStic by default, with melonDS, melonDS DS and DeSmuME as extra cores, and it includes PortMaster on the Pixel 2. Its Wasabi media player plays video, audio and playlists, and even live TV and radio. ZyperOS ships DSperate and runs DraStic if you add it, runs PortMaster ports set up elsewhere, and its MP4 plays music, audiobooks and video. See the DS guide, the PortMaster guide and music and video.

Battery

muOS lights the Pixel 2's side lights in a sweep at start and at shutdown, and leaves the red charge light on after shutdown. Its own Pixel 2 script says the board has no charge boot mode, so there is no charging screen while off. ZyperOS has one, showing the charge, the speed and the time to full, plus a charge limit and side lights for the battery, volume, brightness, transfers and achievements. The battery guide shows them.

Which one to pick

muOS runs on many handhelds, with a broad catalogue, a web dashboard, a guided tour and a rich media player. ZyperOS is narrower and made for the Pixel 2, with covers on the handheld, transfers over the cable, and battery care. Each is a card, so you can try both.
