PortMaster brings PC and indie games to Linux handhelds as ports: Stardew Valley, Celeste and many more, each packed with what it needs to run. ZyperOS has a Ports shelf that runs them on the GKD Pixel 2. This guide explains how ports get onto a ZyperOS card, the game files you supply yourself, and what ZyperOS does when a port runs.

What PortMaster is

PortMaster is a free app, under the MIT license, that downloads and installs game ports on Linux handhelds. Each port carries its own libraries, so it does not change the system it runs on. Most ports of commercial games are not "ready to run": the port is free, but you supply the game's own files from a copy you bought.

PortMaster's list of devices does not name the GKD Pixel 2, though its own FAQ says that list is out of date. Retro Game Corps found PortMaster preloaded on the Pixel 2's stock firmware, and working.

How ports get onto a ZyperOS card

A port is a script, Something.sh, with the port's folder beside it, and PortMaster keeps its own folder, PortMaster/, next to them. On ZyperOS all of that goes in Roms/Ports. The Ports shelf lists each script there, and stays hidden while the folder is empty.

PortMaster's own app, the one that browses and downloads ports, is a Python program. ZyperOS's Linux does not include Python, so that app does not run on ZyperOS. The ports themselves do.

So you set ports up with PortMaster somewhere it runs, and copy the result:

  1. On a card with a system PortMaster runs on, such as the stock firmware or ROCKNIX, open PortMaster and install the ports you want.
  2. Add each port's game files where its instructions say, if it needs them.
  3. Copy that card's ports folder to Roms/Ports on the ZyperOS card: the .sh scripts, their folders and PortMaster/ itself.

Moving from ROGUE OS? ZyperOS's tools/from-rogue.sh copies a ROGUE OS card's library to a ZyperOS card, and it copies the ports layout as it is.

Stardew Valley and Celeste

Both need the game's files from a copy you own, and both run on 64-bit Arm handhelds such as the Pixel 2.

PortThe game files you supplyNotes
Stardew Valley CompatibilityThe game's "compatibility" version, from Steam or GOG, copied into the port's gamedata folderStardew's own lighter build, for systems that cannot run the normal one. It gets the same content updates.
Stardew ValleyThe Windows Steam version, not the compatibility branchMarked experimental. Comes with SMAPI, and some mods can run out of memory.
CelesteThe DRM-free version, from itch.io (Linux) or Epic (Windows), copied into celeste/gamedataThe first run takes a few minutes while it compresses the textures to save video memory.

The Pixel 2 has 1 GB of memory, and a big port like Stardew Valley wants most of it. That is why ZyperOS steps aside while a port runs.

What ZyperOS does when a port runs

  • It frees the memory. ZyperOS's emulator, which normally stays loaded so games start at once, is stopped, and so is MP4, so the port has the memory to itself.
  • It sets PortMaster up for ZyperOS. PortMaster writes its settings for whatever system it was installed on. Before every port, ZyperOS puts its own control.txt, graphics settings and per-system file in PortMaster/, so a port copied from another system finds its way on ZyperOS.
  • The volume keys still work, and MENU with them sets the brightness, with ZyperOS's bar over the port.
  • POWER ends the port and then turns the handheld off, as does a battery at 2%. The port is asked to close first, so a game that saves on exit gets the chance.

When the port ends, ZyperOS comes back.
