On the GKD Pixel 2, the whole system lives on the microSD card. So installing custom firmware does not change the handheld at all: you write the new system to a card and boot from it. Keep the card it came with and you can always go back. This guide covers the steps every system shares, and what is different for ZyperOS, ROCKNIX, TortOS, plumOS and ROGUE OS.

Before you start

  • A second microSD card. Use a new card for the new system, and put the stock card away. plumOS asks for one of at least 16 GB; the others name no minimum. Get one big enough for your games.
  • A card reader for your computer.
  • A program that writes disk images, such as Raspberry Pi Imager or balenaEtcher.

ZyperOS also has ZyperOS Installer, for macOS, Windows and Linux, which downloads its latest release and writes it for you. The ZyperOS section below has its steps.

Step 1: keep the stock card safe

The card that came with your Pixel 2 holds its stock firmware, and some sellers ship games on it too. Writing an image to a card erases everything on it, so do not write over that one. Put it away, and if you want a spare, make a full image of it first with a disk imaging program. To go back to stock at any time, turn the handheld off and put that card back.

Step 3: write the image to the card

  1. Put the new card in the card reader.
  2. Decompress the file if the project says to. ROCKNIX's docs say to decompress the image first, and plumOS's .img comes out of a .7z.
  3. Open the image writer, choose the image and the card, and write. Check twice that you chose the card, not another disk: the writer erases what it writes to.
  4. Eject the card when the writer says it is done.

ROCKNIX's docs name Rufus, Raspberry Pi Imager and Win32 Disk Imager; plumOS's name Raspberry Pi Imager and balenaEtcher; ROGUE OS's notes name balenaEtcher; TortOS's README says any program that writes disk images.

Step 4: the first boot

Put the card in the Pixel 2 and turn it on. The first boot takes longer than the rest, because each system makes the space for your games on the rest of the card:

Step 5: add your games

Every system has its own folder names. On ZyperOS games go in Roms/<console>, and you can send them over Wi-Fi or the USB cable as well as with the card in a computer. The adding games guide shows how.

Installing ZyperOS

ZyperOS 1.0.2 is out for the Pixel 2, released in November 2026. Each release on GitHub has the card image and ZyperOS Installer for macOS, Windows and Linux. To install it:

  1. Download ZyperOS Installer for your computer from the latest release.
  2. Put the microSD card in the computer, then pick the GKD Pixel 2, the latest release and the card. Choose Fresh install, which erases the card. Or write the card image with any program that writes disk images, like Raspberry Pi Imager.
  3. Put the card in the Pixel 2 and turn it on. The first start sets the card up in about a minute. Then Zyper teaches the buttons and asks four things: the theme, the home screen, the button sounds and the menu music.
  4. Set your time zone in MENU > Date & Time. Without Wi-Fi, set the time there too, and it keeps it.

ZyperOS Installer's Update puts a new version on a card that already has ZyperOS and keeps its games, music and saves. On the handheld, System Update brings new versions over Wi-Fi, or over the USB cable from the File Transfer page. To build the card image yourself instead, docs/building.md explains how.

Going back

Turn the Pixel 2 off and put another card in. The handheld starts whatever system is on the card, so the stock card brings the stock firmware back, unchanged. Everything a system keeps, Wi-Fi passwords included, is on its own card: wipe a card before you give it away.
