ROGUE OS, by Ninoh-FOX, is a set of changes to the GKD Pixel 2's own firmware, and it set the bar for what this handheld can do. ZyperOS set out to match it, as a separate system with a Linux of its own. This is the two side by side, from each project's own code and releases as of 7 November 2026.

The short answer

  • Pick ROGUE OS if you want over a hundred systems, DraStic and PortMaster included, with the stock firmware's familiar menus and many launcher skins.
  • Pick ZyperOS if you want games sent from any browser, box art without a computer, RetroAchievements, updates on the handheld, and battery care such as a charge limit. Version 1.0.1 is out, with a card image and ZyperOS Installer.

What each one is

ROGUE OS's README calls it changes made to the original system: the stock firmware's system file is unpacked, improved and packed again, with a newer kernel build and RetroArch 1.21.0. So it keeps the stock firmware's IUX menu and EmulationStation, and adds to them. It is made for the GKD Pixel 2 alone.

ZyperOS is not built on the stock firmware. Its launcher, its emulator frontend Diatom, and its Linux, plastron, all began as Eric Reinsmidt's TortOS, and run games through libretro cores. Diatom stays running, so a game starts the moment you press A.

Installing

ROGUE OS installs in steps: download its first release's image, about 5.7 GB in six parts, and write it with a tool like balenaEtcher; resize its ROMS partition with a partition tool; then copy the newest release's Image and SYSTEM files over the ones on its EMUELEC partition. The first start may turn the handheld off once, as a file check. ZyperOS's release has a card image you write with any image writer, and ZyperOS Installer, which downloads and writes it for you. The install guide has both.

Adding games and box art

On ROGUE OS, the default EmulationStation offers the USB cable as a file-transfer device, and SSH works over a network as root. Its Scraper app, in Tools, fetches images from ScreenScraper with your account. ZyperOS opens one web page in any browser, over Wi-Fi, its own network or the USB cable, and fetches covers from libretro with no account, from ScreenScraper and from SteamGridDB. See adding games and box art.

Nintendo DS and PortMaster

ROGUE OS includes Steward Fu's DraStic and a second DraStic build, plus melonDS and DeSmuME, and PortMaster, with its runtimes from a file on its releases page. On DraStic, R2 turns the stylus on and L2 swaps the screens. ZyperOS ships DSperate, an open DS emulator, with the same shoulder idea: R2 for the stylus, L2 for the other screen, and three layouts. It runs DraStic too if you add it, and takes DraStic's saves over. ZyperOS installs PortMaster from its Ports shelf with one press, over Wi-Fi. See the DS guide and the PortMaster guide.

Battery

ROGUE OS vibrates three times at 10% and at 5%, and at 1% it stops the game and shuts down safely to protect the card. Its "Charging screen off" tool turns the screen off and sets the chip to save power while the handheld charges. ZyperOS warns on the screen and with the side lights, saves the game and powers off at 2%, shows the charge and the time to full on a charger while off, and can stop charging at 80, 85 or 90%. The battery guide shows them.

Updates

A new ROGUE OS release is files you copy onto the card's EMUELEC partition. Its newest is 1.22, from August 2025. ZyperOS's System Update works over Wi-Fi, downloads only what changed, and goes back by itself if a new version fails to start. Without Wi-Fi, the File Transfer page brings it over the USB cable.

Moving from ROGUE OS to ZyperOS

ZyperOS has a tool for this, tools/from-rogue.sh. Pointed at a ROGUE OS card's games and a ZyperOS card, it copies every game, BIOS file and battery save ZyperOS has a place for, copies the PortMaster ports layout as it is, and reports what has no place. It only reads the ROGUE OS card and never writes over a file already on the ZyperOS card. Keep the ROGUE OS card as it is: it stays your way back.

Which one to pick

ROGUE OS covers more systems, and its DraStic and PortMaster are ready on the card. ZyperOS covers fewer systems for now, with a newer design: web transfers, covers and achievements on the handheld, updates that roll back, and battery care. ROGUE OS made ZyperOS what it is. Each is a card, so you can keep both.
