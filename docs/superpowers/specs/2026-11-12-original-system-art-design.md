# Original system art

## Approved direction

The user approved the new Game Boy art and its screen animation on 2026-11-12.
The user requested more Game Boy resolution, more systems, and a PlayStation lid animation.
Each handheld shows its own original startup sequence.
Systems without screens show media loading, a moving lid, or power controls.

## Art

Create new hardware illustrations with the built-in image tool.
Do not use the public icon pack as source pixels.
Do not reduce hardware photos into replacement art.
Use transparent backgrounds, clear controls, flat color groups, and consistent outlines.
Keep the hardware shape and controls accurate.
Record prompts and image origins with each source.
The hardware makers retain their names and marks.

## Animation

Increase the Game Boy preview from 128 to 256 pixels per side.
Keep its displayed size unchanged.
Keep the case still while the screen shows the original Nintendo logo scroll.
The PlayStation lid rotates about its rear hinge, opens, holds, and closes.
Keep its case, controller, and cable still.
Use the same fixed base for all animation frames to prevent frame-to-frame changes.
For 3DO, move the disc tray forward and back.
For cartridge systems, insert the correct cartridge and then show the power light.

## Approaches

The initial options used front views, shallow three-quarter views, or larger detailed views.
The approved samples use clear front views for handhelds and shallow three-quarter views for consoles.
The higher resolution preserves the screen detail and the established size.
Separate screen and mechanical layers keep the case stable.
