# Beard and Salt & Pepper on every screen: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every screen the launcher draws takes its colors, scrims, frame, radii, focus fill and lift from the current theme, chosen by MENU > Appearance (Light, Dark, Auto), with Light the default.

**Architecture:** `src/theme.c` owns the current theme: it resolves the Appearance setting (and the clock, for Auto), exposes `const ds_theme *theme(void)`, and writes `/tmp/zyperos-theme` (phase 1's `themefile_write`) when the theme changes. `ui.h`'s color names become calls into it; every color literal the audit found is replaced by a role. Lift is one helper, `ui_lift`, that glows in Salt & Pepper and casts a shadow in Beard.

**Tech Stack:** C11, SDL2, SDL2_ttf; `src/design.h` from `tools/designdef.py`.

**Spec:** `DESIGN.md` 3 (color, scrims), 6 (shape), 7 (elevation), 11 (components), 12 (copy); the audit in the shared notes (`ux-design-audit.md`) lists every literal by file and line.

## Global Constraints

- Code names roles, never values: no RGB literal outside `src/design.h`, `src/zypermark.h` and generated card art. (Exceptions the audit marks intentional keep their literal with the comment that says why.)
- Default theme for a new device: Light (Beard). Setting key `appearance` in the device database: `light`, `dark` or `auto`. Auto is light from 7:00 to 19:00 local time.
- Scrims: **scrim.menu** under every menu, keyboard and one-line message over the shelf; **scrim.game** under every panel over a paused game.
- Panel: **surface**, radius `DS_RADIUS_PANEL` (28), a `DS_FRAME` (3) frame in **edge** (`UI_PANEL_BORDER` becomes `DS_FRAME`). The focused row: **accent** fill, radius `DS_RADIUS_ROW`, label and value **on-accent**.
- A system's color as a mark on Beard is mixed 25% toward **text** (`ui_mix(acc, text, 0.25)`).
- Muse's green and every cyan become **accent** (fills) or **accent-ink** (marks, earned).
- **Appearance** selects Light, Dark, or Auto. The shelf has no card-style selector.

## Review Focus

1. Auto crossing 7:00 or 19:00 while a menu is open: the next frame is drawn in the new theme, and the theme file follows.
2. A system with no color in systems.cfg on Beard: its marks use **text-dim**, not the old cyan.
3. Generated cards (games with no art) in Beard: readable title on the light slab.
4. The in-game menu over a bright game in Beard: **scrim.game** keeps the panel readable (same 73% in both themes).
5. A theme change with textures already cached (generated cards, glyphs, the bar's texture): they are rebuilt, not shown in the old theme.

**Interfaces:**
