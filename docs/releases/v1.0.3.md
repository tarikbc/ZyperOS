ZyperOS 1.0.3 makes USB simple and safe: File Transfer over the cable works on more computers, the Pixel 2 asks before it powers anything you plug in, and File Transfer stays cool.

## Install

1. Download **ZyperOS Installer** for your computer below: macOS (`.zip`), Windows (`.exe`), or Linux (`.deb` or `.rpm`).
2. Put the microSD card in the computer, open the installer, and pick the GKD Pixel 2, the latest release and the card. **Fresh install** erases the card and puts ZyperOS on it.
3. Put the card in the Pixel 2 and turn it on. The first start sets the card up (about a minute), then asks for your language, and Zyper shows you each button.

Or write `ZyperOS-v1.0.3-pixel2.img.xz` with any disk image writer (Raspberry Pi Imager, balenaEtcher). Check it against `SHA256SUMS` first.

## What's new

- **http://zyperos.local:** USB File Transfer now has a name you can type, next to its address. The page opens from any browser on the computer, and the address now wins over any other network that uses the same numbers, which fixes File Transfer on some Windows 11 computers.
- **The connection, step by step:** File Transfer shows Cable, Address and Browser as they connect, and if one stalls, a short hint says what to do. It counts browsers, not connections, so one browser shows as one.
- **"What did you plug in?":** when something on the USB port wants power, the Pixel 2 asks: a USB accessory (headphones, a Wi-Fi adapter, a keyboard) or a computer. It never powers a computer by itself. If a computer doesn't connect, the Pixel 2 tells you to plug the cable in again. Answered by mistake? The USB mark at the top, or **MENU > USB Device**, asks again.
- **MENU > USB Accessories:** keep it on **Ask**, or set **Automatic** to power accessories right away with no question.
- **Cooler File Transfer:** the File Transfer screen and the open MENU no longer redraw when nothing changes. On my Pixel 2, File Transfer left open on the cable now stays around 37 °C instead of passing 50 °C, and uses a sixth of the battery. Its screen turns off after Auto Off, and only dims while files are copying.
- **Button hints** in the new questions show each button's glyph, the same way everywhere.
- **Fixes:** the Pixel 2 is recognized by a Mac on the first plug, and longer words, like "auto (alto-falante)" in Audio Output, no longer get cut.

## Updating from 1.0.2

**MENU > System Update** offers **System and ZyperOS** over Wi-Fi or the USB cable: this release updates the system too, for the USB changes. Or use **Update** in ZyperOS Installer, which keeps your games, music and saves.

## Good to know

- **The GKD Pixel 2 only.** The TrimUI Brick's image comes in a later release.
- **Not included, add them if you want:** BIOS files, which go in `Bios/`. The README lists each one.
- **Your own games only.** ZyperOS comes with no games.
