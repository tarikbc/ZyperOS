ZyperOS 1.0.4 fixes USB File Transfer on every computer, adds a Flash Drive mode that needs no driver at all, and lets System Update download in the background and pick up where it stopped.

## Install

1. Download **ZyperOS Installer** for your computer below: macOS (`.zip`), Windows (`.exe`), or Linux (`.deb` or `.rpm`).
2. Put the microSD card in the computer, open the installer, and pick the GKD Pixel 2, the latest release and the card. **Fresh install** erases the card and puts ZyperOS on it.
3. Put the card in the Pixel 2 and turn it on. The first start sets the card up (about a minute), then asks for your language, and Zyper shows you each button.

Or write `ZyperOS-v1.0.4-pixel2.img.xz` with any disk image writer (Raspberry Pi Imager, balenaEtcher). Check it against `SHA256SUMS` first.

## What's new

- **File Transfer over the cable works again:** on the release images, the Pixel 2 never finished setting up its side of the USB connection, so the computer saw a dead link and the screen blamed a missing driver. Plug in, choose File Transfer, and http://zyperos.local opens.
- **Flash Drive:** a new choice when you plug into a computer. The Pixel 2 shows up as a regular USB drive on any computer, with no driver and no browser, Windows 10 included. Its screen shows the download and upload speed live, MENU and the volume buttons set the brightness, and B ejects from the Pixel 2 itself. Eject it on the computer, or press B, and ZyperOS comes back.
- **A new Computer Connected screen:** its choices in a 2x2 grid, starting on Charge Only.
- **System Update in the background:** start a download and keep playing. A mark at the top shows its progress, and Zyper tells you when it is ready to install. The Pixel 2 no longer turns itself off in the middle of a download.
- **Downloads pick up where they stopped:** if Wi-Fi drops or the Pixel 2 turns off, the download goes on from the same spot next time, by itself.
- **New releases come to you:** each time Wi-Fi connects, ZyperOS checks for a new release and tells you once.
- **Readable release notes:** System Update shows each point in full, and Up and Down scroll them.
- **Charge to 100% this once:** on the charging screen, Y charges to full one time, even below your charge limit. The limit comes back when you unplug.
- **Wi-Fi adapters after a power-off:** a USB accessory that was powered when you turned off gets power again at the next start, with no question. Questions also ignore a button you were already holding when they appeared, and the message when a computer doesn't connect says what to do.
- **Game clocks in your time zone:** games with a clock, like Pokémon's day and night, now follow the zone chosen in Date & Time instead of UTC.
- **Video previews in their real colors:** previews on the shelf had red and blue swapped.
- **Button hints everywhere:** Bluetooth, Wi-Fi, Play Time, Date & Time, File Transfer and more show each button's glyph, the same way everywhere.
- **The keyboard matches the menus:** the same spacing, heading and line as every other panel.
- **A USB log for support:** File Transfer's "Download logs" now includes the last 50 USB plugs.

## Updating from 1.0.3

**MENU > System Update** offers **System and ZyperOS** over Wi-Fi, because Flash Drive needs the new system. On 1.0.3, File Transfer over the cable doesn't connect, so update over Wi-Fi, or use **Update** in ZyperOS Installer, which keeps your games, music and saves.

## Good to know

- **The GKD Pixel 2 only.** The TrimUI Brick's image comes in a later release.
- **Not included, add them if you want:** BIOS files, which go in `Bios/`. The README lists each one.
- **Your own games only.** ZyperOS comes with no games.
