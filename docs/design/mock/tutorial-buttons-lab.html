Tutorial: where the buttons are

The tutorial names each button, but MENU, the volume keys and POWER are on the sides of the GKD Pixel 2, where a new player does not look. Each lesson now shows the handheld beside the stage with that lesson's button lit in lime. The figure is drawn in code from the landing page's 3D model (its millimetre measurements), in the theme's own colors, so it costs no memory and no assets. The stage and the words are real launcher frames; only the figure is new.

Pick one, and say what to change in the note. Use the lesson buttons, or Play all to see the lessons follow each other.
