ZyperOS in five languages

Every word on the handheld will come from one table: the launcher, the in-game menu, the File Transfer page, and the boot and charging screens. A language change is one pointer swap, so it costs no frames. These are the choices that are yours: which five, how the first start asks, where MENU keeps it, and the words.

Try the first-start screens with the pad (or the arrow keys and Enter): UP and DOWN look at a language, and the screen speaks it at once. Pick one option in each section. Write any change in the note.
