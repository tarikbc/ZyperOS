Wi-Fi File Transfer when the handheld is on no network: it makes its own Wi-Fi, and a phone joins by scanning a code on the screen. The phone's sign-in sheet then opens the transfer page by itself, and the PIN still guards it.

Connecting…

Kept in every option. Each time the screen opens, the handheld makes a new password and a new PIN; both die when it closes, and normal Wi-Fi comes back. On a network, the screen stays as it is today.
  1. The phone scans the code with its camera and joins (Wi-Fi password, WPA2).
  2. The phone shows its sign-in sheet, which opens the transfer page at 10.42.1.1.
  3. The page asks for the PIN, as today.
The codes on this page are pictures only; they do not scan. One module of the code is 8 units, five panel pixels, so the code is about 3.7 cm wide on the Pixel 2.
