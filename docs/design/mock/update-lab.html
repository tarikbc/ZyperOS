ZyperOS Update Lab

System Update for the card's ZyperOS folder: the launcher, Diatom, the cores and the art. It downloads only the files that changed, checks every file against a signed list, and keeps the old version for one step back. These three decisions set where it lives, how it looks, and when it looks for updates.

Connecting…

Kept in every option. Nothing installs while you play: the new version goes into a separate folder and is switched in at the next start. Below 25% battery without the charger, the download does not start. A download that stops (Wi-Fi gone, power off) continues where it stopped. If the new version does not start twice, the next start goes back to the old one by itself.
