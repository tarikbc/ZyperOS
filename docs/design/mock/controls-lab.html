In-game controls lab

Two changes. First, a Controls row in the in-game menu: a page that lists every control that works in this game, on this system. Second, the systems in A to Z order on the home. Pick one option in each section, and add a note if you want a change. Every option is shown in Beard and in Salt & Pepper. Play shows the presses, with the menu's sounds.

Connecting…

Kept in every option
  • One source: the page is built by src/controls.c, the same file as MENU > Controls on the home. The hotkey rows are the home's own rows, so the two pages cannot disagree.
  • Read from the cores: each system's button names come from its core, measured from the pinned cores on 2026-11-06 (the names each core gives the RetroPad buttons), then put through the system's own map (Dreamcast, NAOMI, Atomiswave, Saturn, J2ME) and its turbo. So a Neo Geo Pocket's A is the B cap, as its core reads it.
  • Only what is true: no row for a button that does nothing on that system. There is no save-state or screenshot hotkey today: Save and Load are menu rows.
  • Paged like the home's: Left/Right turns the page, B goes back to the menu, MENU goes back to the game. Read-only, over the paused game, in the standard panel.
  • No cost in a game: the page is built when it opens, from tables in the launcher. Nothing runs while the game plays, and the game starts as fast as today.
  • A to Z: by the full name, as the Gallery shows it. Case and accents do not count, and numbers count as numbers: 3DO before 32X, Atari 2600 before Atari Lynx. Sorted once when the card is read, never per frame.
