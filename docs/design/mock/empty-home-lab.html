Empty home lab

The home when the card has no games yet. It tells you how to add games, and one button starts each way. Every option is shown in Beard (light) and Salt & Pepper (dark). Pick one option in each section, and add a note if you want a change.

  • USB File Transfer: the port only charges until you choose. Plug into a computer, choose File Transfer on the question (or press A here), then open 10.42.0.1 in the computer's browser and type the PIN the handheld shows.
  • Wi-Fi File Transfer: the Pixel 2 needs its USB Wi-Fi adapter in the same port. On your Wi-Fi it shows its address and a PIN; with no network it makes its own (ZyperOS-XXXX, with a code to scan).
  • So on the Pixel 2 only one way works at a time: the cable, or the adapter. The screen can follow what is plugged in (section 2).
  • When a transfer adds games, the home becomes Spotlight or Gallery at once, with no restart.
