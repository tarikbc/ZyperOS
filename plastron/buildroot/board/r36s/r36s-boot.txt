# The R36S test card's boot settings, read by its boot script before it
# starts Linux. Edit on any computer; a line starting with # is off.
#
# BLACK SCREEN? R36S units come with different screens (panels), and the
# card cannot tell which one yours has. With nothing set here it drives
# panel 4, the panel of most R36S boards that dArkOSRE has device trees
# for (R36S-V12, V20, V21, V22). If the screen stays black, take
# the # off the zy_panel line below, put the next name after the =, save,
# and start the R36S again. Try them in this order: 0, 4v22, 2, 3, 1.
#zy_panel=0
#
# The panels' overlays are in overlays/ on this partition (panel-0.dtbo ...
# panel-4.dtbo, panel-4v22.dtbo). For a panel none of them lights, make the
# unit's own from the device tree on the card it came with
# (plastron/scripts/r36s-panel.py, ZyperOS's docs/devices/r36s.md,
# "Panels"), copy it here as overlays/panel-mine.dtbo and write
# zy_panel=mine. An overlays/mipi-panel.dtbo here is used when no zy_panel
# is set. Or any other file:
#zy_overlay=overlays/my-panel.dtbo
#
# The sound output: HP (the default, the speaker and the headphones both
# play) or SPK (the RK817's class D speaker output alone, the GKD Pixel 2's
# speaker path; headphones may sound wrong on it).
#zy_audio=SPK
#
# The device tree: ZyperOS's (the boot card first among the SD cards), or
# ROCKNIX's own, unchanged (its card is then mmcblk1, and the system will
# not find its root).
#zy_dtb=rk3326-gameconsole-r36s.dtb
#
# The kernel's line, for debugging (the serial port is ttyS2 at 1500000):
#zy_args=rootfstype=squashfs ro rootwait console=ttyS2,1500000 console=tty1 panic=0 loglevel=8 watchdog.open_timeout=60
#
# A restart by the chip itself (its watchdog) also restarts the power chip,
# so the card comes back from it. For a clone where that starts nothing:
#zy_pmicrst=0
