# Exports the kernel keeps although nothing in its own tree uses them: every
# symbol Realtek's rtl8188eu driver (package rtl8188eu, the ZyperOS image's
# driver for the RTL8188EU adapters, which can be an access point) takes from
# the kernel and from cfg80211. linux-px2.config builds with
# CONFIG_TRIM_UNUSED_KSYMS, which exports only what the in-tree modules use,
# and without this list the driver loaded with "Unknown symbol" for
# everything from vfree to netif_tx_wake_queue: no wlan0, no Wi-Fi at all.
#
# One symbol a line; a line that names no symbol (these) is passed over.
# Made with `aarch64-buildroot-linux-gnu-nm -u 8188eu.ko`; make it again when
# rtl8188eu changes.
